4 · Componentes de Formulário

A aplicação possui apenas input de texto e botão (botão documentado na Seção 6). Não há select, checkbox, radio, toggle, textarea, date picker nem file upload no original — omitidos.

4.1 — Inputs de Texto (.industrial_input)

Estados Focus / Error via / :focus. O original não define estados error, disabled nem tamanho sm/md/lg para o input. Read-only aparece no formulário de bipage.

Label (.input_label)

Label sempre acima do campo (input_group = flex column, gap 6px). Sem helper text nem mensagem de erro no original.

4.2 — Composição de Formulário (extraído do original: Bipage / Lançamento de OP)

Padrão: .form_box (padding 24px) → .form_grid (auto-fit minmax 200px, gap 16px) → .input_group (coluna) → botão de ação alinhado à esquerda abaixo do grid.

Padrões de layout extraídos

1) Listagem: content_area → factory_alert (opcional) → grid_kpi → table_wrapper. 2) Formulário: content_area → form_box → form_grid (2 colunas) → btn_apple à esquerda. 3) Dashboard: content_area → grid_kpi de KPIs. A aplicação original usa apenas tema claro e não declara breakpoints — responsividade vem do auto-fit dos grids (KPI em 240px, formulário em 200px).
